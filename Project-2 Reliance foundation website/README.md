# Reliance Foundation Scholarship Portal Clone

This project is a clone of the Reliance Foundation Scholarship Portal, created using HTML and CSS for learning and practice purposes. The aim of this project is to replicate the design and layout of the original portal while improving frontend development skills.

---

## Project Overview

The Reliance Foundation Scholarship Portal Clone is designed to mimic the appearance and structure of the official scholarship application website. This project focuses on:

- Building a responsive and visually accurate user interface.
- Strengthening HTML and CSS fundamentals.
- Practicing layout structuring and styling techniques.

---

## Features

- Responsive design
- Clean and organized codebase
- Modern and professional UI
- Semantic HTML markup
- CSS Flexbox and Grid layout implementation

---

## Technologies Used

- HTML5  
- CSS3
