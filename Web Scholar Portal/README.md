# Web Scholar - Scholarship and Education Loan Portal

This project is a front-end design of **Web Scholar**, a Scholarship and Education Loan Portal, created using **HTML** and **CSS**. The portal provides users with options to explore various scholarship opportunities, education loan assistance, and guidance for studying abroad.

This project is designed for learning purposes and focuses on creating a professional, structured, and responsive website layout.

---

## Project Overview

The **Web Scholar** portal is designed to simulate a real-world scholarship and loan guidance website. The user interface is structured to allow easy navigation for students looking for:

- Scholarship programs.
- Education loan options.
- Study abroad guidance and resources.

The main goal of the project is to enhance front-end development skills and practice responsive web design using HTML and CSS.

---

## Features

- Clean and structured user interface.
- Dedicated sections for scholarships, education loans, and abroad study guidance.
- Responsive layout for desktop and mobile devices.
- Organized and maintainable HTML and CSS codebase.

---

## Technologies Used

- HTML5  
- CSS3
